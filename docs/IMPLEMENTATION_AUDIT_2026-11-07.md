# گزارش اصلاح اتصال، بک‌اند و پالیش رابط

تاریخ: ۲۰۲۶/۱۱/۰۷. بررسی روی کد فعلی پروژه و خروجی ساخته‌شدهٔ برنامه انجام شد. رنگ‌ها، فونت‌ها و چهار تم موجود حفظ شدند.

## اصلاحات عملی

- مهاجرت دهم MySQL به‌دلیل ناسازگاری charset ستون‌های UUID با کلیدهای خارجی اجرا نمی‌شد. ستون‌ها با `ascii_bin` هماهنگ شدند؛ مهاجرت‌های ۹ و ۱۰ روی دیتابیس محلی اعمال و ساخت دیتابیس تازه هم آزمایش شد.
- هر کلاس اکنون یک WebSocket مشترک دارد. اتصال پس از پیام آماده‌بودن سرور تأیید می‌شود؛ heartbeat، تشخیص سکوت ارتباط، تلاش مجدد با فاصلهٔ افزایشی و بازیابی پس از برگشت شبکه اضافه شد. همگام‌سازی دوره‌ای HTTP، پیام‌های از‌دست‌رفته و رویدادهای نمونه‌های جداگانهٔ API را جبران می‌کند.
- وضعیت واقعی اتصال سرور و دیتابیس در ورود و فضای کاری، و وضعیت اتصال زنده در کلاس نمایش داده می‌شود. endpoint بررسی اتصال، پرس‌وجوی واقعی دیتابیس اجرا می‌کند.
- درخواست‌های API مهلت زمانی دارند؛ لغو درخواست و تعویض سازمان/کلاس، پاسخ‌های قدیمی را از تغییر صفحهٔ جدید بازمی‌دارد. ذخیره‌های خودکار یادداشت، اعلان خطای تکراری روی کنترل‌های کلاس ایجاد نمی‌کنند.
- شکست سرویس اختیاری ارائه یا سند، دریافت وضعیت اصلی کلاس را متوقف نمی‌کند. تغییرات هم‌زمان کلاس، فرم باز تنظیمات را بازنویسی نمی‌کنند.
- لغو دسترسی فردی تخته در ویرایشگر قدیمی، تختهٔ پیشرفته و نشانگر حضور یکسان اعمال می‌شود. اولویت نقش ارائه‌دهنده برای اشتراک صفحه نیز هماهنگ شد. فهرست ایمیل‌ها و مجوزهای مدیریتی برای دانشجو قابل خواندن نیست.
- URL رسانهٔ خارجی فقط با پروتکل HTTP/HTTPS پذیرفته می‌شود. اعلان سنجاق‌شده، تنظیمات، واکنش، پاک‌کردن چت، قفل و اخراج/بازگرداندن کاربر با مرزهای نقش آزمایش شدند.
- مسیر نسبی فضای خصوصی فایل‌ها در اجرای سورس و سرور کامپایل‌شده یکسان شد. worker به همان فضای خصوصی متصل شد و گروه لازم برای خواندن خروجی تبدیل دریافت کرد. فایل قبلیِ ایجادشده هنگام بررسی نیز بدون جایگزینی فایل متفاوت، به مسیر مشترک کپی شد.
- سربرگ کلاس دیگر پشت محتوای صحنه نمی‌شکند. اندازهٔ پنل‌ها، حداقل عرض gridها، ارتفاع اسناد و اعلان، پنجره‌های قابل اسکرول، اندازهٔ تنظیمات، نوار کناری و نمایش موبایل/افقی اصلاح شدند. پیش‌نمایش بزرگ تم از dialog واقعی با مدیریت فوکوس و Escape استفاده می‌کند. اعلان‌ها کلیک روی بخش‌های زیر خود را مسدود نمی‌کنند.
- چت هنگام خواندن پیام‌های قدیمی به انتها نمی‌پرد؛ ارسال پیام همچنان پیام جدید خود کاربر را نشان می‌دهد. اعتبارسنجی ثبت‌نام خطای مرتبط را کنار فیلد و با فوکوس همان فیلد نمایش می‌دهد.

## حدود نتیجه و اجرای محلی

سه تست اجرا‌نشدهٔ مجموعهٔ backend، آزمون converter مخصوص Linux، بازیابی dump و provider واقعی S3 بودند. تبدیل PDF/DOCX و ارائهٔ خصوصی به‌صورت مستقل با worker واقعی Linux بررسی شد؛ تست کامل converter همراه اسکن آنتی‌ویروس در این اجرای Windows انجام نشد. فضای فایل فعلی filesystem محلی است؛ نتیجهٔ این بررسی تأیید یک provider جدید S3 یا زیرساخت production نیست.

پیش‌نمایش فعلی: `http://localhost:5173`؛ API روی پورت ۳۰۰۱، MySQL واقعی، SFU محلی و worker جداگانه فعال‌اند. `PRESENTATIONS_ENABLED=true` پس از موفقیت تبدیل واقعی در تنظیمات محلی ثبت شد. فایل‌های حاوی کلید و حساب آزمون در `.local` و `.env` هستند و نباید عمومی شوند.

برای اجرای سرور کامپایل‌شده، دستور را از ریشهٔ پروژه اجرا کنید: `node --env-file=.env build/server/apps/api/src/main.js`. مسیرهای نسبی فایل‌ها از پوشهٔ اجرای فرایند محاسبه می‌شوند؛ API و worker باید به همان فضای خصوصی دسترسی داشته باشند. در راه‌اندازی دوبارهٔ WSL، تغییر IP سرویس رسانه باید در تنظیمات محلی اعمال شود. سرویس‌های فعلی یک استقرار محلی هستند؛ بازیابی خودکار ارتباط جایگزین در دسترس‌بودن دیتابیس، شبکه و SFU نمی‌شود.

این گزارش به قسمت‌های موجود رابط و اصلاحات بررسی‌شده مربوط است. بخش‌های برنامه‌ریزی‌شدهٔ محصول در `FEATURE_PARITY.md` همچنان باید با وضعیت واقعی خود پیگیری شوند؛ نتیجهٔ این کار به معنی پیاده‌سازی تمامی نقشهٔ راه آن فایل نیست.
